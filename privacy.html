시행일: 2026년 11월 10일

「지워진도서관 업로드 도구」(이하 '도구')는 유튜브 채널 「지워진 도서관」 운영자가 자기 채널에 영상을 올리기 위해 직접 만든 내부용 프로그램입니다. 외부 이용자에게 제공하지 않습니다.

1. 사용하는 정보

도구는 Google OAuth를 통해 운영자 본인의 YouTube 계정에 대한 권한(영상 업로드, 썸네일·자막·재생목록 관리)만 요청합니다. 이름, 이메일, 연락처 등 다른 개인정보는 수집하지 않습니다.

2. 사용 목적

받은 권한은 운영자 채널에 영상과 썸네일, 자막을 올리고 공개 예약을 설정하는 데에만 씁니다.

3. 보관과 공유

인증 토큰은 운영자 PC 안에만 저장되며, 어떤 서버로도 전송하거나 제3자와 공유하지 않습니다. 운영자는 언제든 Google 계정 설정(보안 → 타사 앱 액세스)에서 권한을 취소할 수 있고, 취소하면 저장된 토큰은 더 이상 쓸 수 없습니다.

4. Google API 사용 정책 준수

도구가 Google API에서 받은 정보의 사용과 다른 앱으로의 이전은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 도구는 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다.
